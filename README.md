# Personal Portfolio Website

## Overview

This project is a personal portfolio and resume website developed for SWE-4633 (Cloud Software Development). The website serves as an online portfolio showcasing personal information, skills, projects, professional experience, and contact information.

The project was built using HTML, CSS, and JavaScript and deployed using GitHub Pages to make the website publicly accessible.

## Features

- **Home Page:** Introduction and overview of the portfolio.
- **About Page:** Personal background and additional information.
- **Resume Page:** Education, work experience, and professional background.
- **Skills & Projects:** Overview of technical skills and completed projects.
- **Contact Page:** Contact form with input validation.
- **Social Links:** Working links to GitHub and LinkedIn.
- **Form Validation:** JavaScript validation to help ensure submitted contact information is valid.
- **Cloud Deployment:** Hosted publicly using GitHub Pages.

## Getting Started

### View the Website

The website is deployed through GitHub Pages:

[**View Live Website**](https://the25thturtle.github.io/SWE-4633-Assignment-1/)

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/The25thTurtle/SWE-4633-Assignment-1.git
   ```

2. Navigate to the project directory.

3. Open `index.html` in your web browser.

No additional dependencies or installations are required.

## Deployment

The website was deployed using **GitHub Pages**.

1. The project source code was uploaded to a public GitHub repository.
2. GitHub Pages was configured through the repository settings.
3. The website was published and made accessible through its GitHub Pages URL.
